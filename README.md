# Replicate-Learning（复刻式学习）

**照着一个成熟项目，把每个文件先讲懂、再直接复刻成自己的代码，快速学会它。**

> 目的：**快速学习**——直接复刻（配置/目录等惯例从原项目抄，机制/算法也从原项目复刻）并讲透原理，不强制使用者手写第一版。非强制规范，适配而非照抄。

---

## 它是什么 / 解决什么问题

一个人想学会一个成熟开源项目（看源码、能讲清每个机制、能复刻一份），最容易踩的坑：看完就忘、动手不会、每个类都写一长篇却抓不住重点、写到一半断了下次不知道从哪继续。

这个技能给出一套可操作流程：**把项目拆成阶段** → **每批先写码 + 按「相关类聚合」分批，逐件先讲懂（六段）再直接复刻** → **每个文件都讲满深度（不分级、不降档）** → **每批立即构建验证** → **讲解全文落盘 + 逐阶段归档**（进度+地图笔记落盘，下次无缝续传）。

它只负责「学习复刻」这一件事，不碰"从想法做一个新产品"那类场景。

## 怎么用（How it works）

**1. 先确认在哪个目录复刻。（重要）**
先问使用者在哪做这次复刻。规范：**官方项目与复刻目录放同一级**。
- 本地已有源码：在**该项目父目录**下建复刻目录。例 `D:\dev\myapp` → `D:\dev\myapp-replica`。
- 给的是 GitHub/远程地址：先定一个"项目根"，官方 clone 进去，复刻目录也在**同级**。例 `D:\projects\myapp-book`（官方，只读）+ `D:\projects\myapp-replica`（你的复刻）。
- 好处：`diff` 对照方便、官方只读互不干扰、路径短好找。

**2. 在复刻目录建"开局三件套"。**
- `AGENTS.md`：项目名 + 当前进度 + 学习资料指针（模板见 `references/`）。
- `NOTES/阶段对照-完整性地图.md`：把官方项目交付面拆成阶段勾选清单，**★ 标出机制较难、讲透要多花时间的类**（★ 只是"重点/难点"提示，不再是讲解深度开关——所有文件都同样满深度）。
- `docs/阶段0-开工清单.md`：跑通官方项目的命令序列。

**3. 分阶段，逐阶段直接复刻 + 讲解。**
读教材对应章 → 跑通参照 → 读答案卷对应类 → **直接复刻（样板抄 / 机制复刻）+ 讲透** → `diff` 对照 → **每批立即构建验证** → 讲解全文落盘 + 归档 + 勾地图 + 更新进度表 + commit。某个阶段件多了就按「相关类聚合」分批，多轮次依次实现。

**4. 每一件都满深度，不做分级。**
不再出《讲解分级表》、不再分「满深度 / 中等 / 精简」档位——不管这个文件是复杂机制还是一个 3 行的 DTO、一段建表 SQL 或一个配置，**六段都完整走一遍、讲到新手能看懂每一行为止**。区别只在**份量**（机制行多、零件/脚本行少），**不降讲解深度、不缩结构**。节奏靠**分阶段 + 按主题分批**控制，不靠降深度省时间。

**5. 每件按"六段"讲透。**
业务场景 → 业务闭环定位 → 类清单表 → 开发四问（思路 / 设计决策 / 手法 / 数据流与边界）→ 代码逐行 + 每手法反例 → 调用链（≥8 跳带类名）→ 用法（可照跑 + 触发回放 + No-Framework 手写版）。

**6. 续传。**
每阶段归档到 `AGENTS.md` + 完整性地图 + `NOTES/阶段N`，讲解全文落盘到 `NOTES/教学讲解/`。下次说「继续复刻 / 接着做」，它读这些文件从当前状态接着来，**不靠对话记忆**。

## 一个例子

你想学会并复刻一个开源知识库（RAG）项目：

1. 你说："我想学会并复刻这个知识库项目。" 它先问你在哪复刻。你给本地路径 `D:\dev\kb-src`；它建议复刻目录 `D:\dev\kb-replica`（同级），并在里面建 `AGENTS.md` + `NOTES/阶段对照-完整性地图.md` + `docs/阶段0-开工清单.md`。
2. 阶段0：跑通官方项目，看到"提问→检索→带引用回答"的效果。
3. 阶段1：拆地图，标 ★（如 RRF 排名融合、重排、幂等导入）。出《类清单表》。
4. 逐批：按「相关类聚合」分批，每批先写出全部文件（含逐行中文注释）→ 再逐个文件照码讲六段（每个都满深度）→ `diff` 对照 → 每批立即构建验证 → 讲解落盘。
5. 每批归档 `NOTES/阶段N` + `NOTES/教学讲解/` + 勾地图 + 更新进度表 + `commit`。
6. 下次开新会话说"继续复刻"，它读 `AGENTS.md` + 地图 + `NOTES/阶段N` 接着做，不丢进度。

```
│   └── 复刻式学习方法-通用.md           全量方法论（文前目录；每类讲解标准；各模板出处）

│   ├── 黄金样例.md                     六段达标基准（满深度示范 + 通俗度/底层穿透对照 + 产出自查）

    ├── 类清单表模板.md                本批每个该复刻文件 + 一句「是什么/它干嘛的」

```

## 安装

这是一个标准 Agent Skill：一个目录 + 一个 `SKILL.md`（frontmatter 仅 `name` + `description`，符合 [Agent Skills 规范](https://agentskills.io/specification)）。

```bash
# 把 skills/replicate-learning/ 整个目录放进你的技能目录即可：
#   ~/.agents/skills/replicate-learning        (Claude Code / Codex / Gemini CLI 均识别 ~/.agents/skills/)
#   ~/.claude/skills/replicate-learning
```

装好后，对一个学习/复刻项目说「我想复刻这个项目 / 读 AGENTS.md 继续阶段 N」即可触发。

## 讲解深度（概述）

| 档位 | 判定 | 深度 |
|---|---|---|
| **满深度（每一件）** | 不分级——不管机制 / DTO / 建表脚本 / 配置，一律满深度 | 六段全量（具名人物+数值、≥8跳调用链、整方法逐行+V三问注释、开发四问含设计决策、用法+触发回放+No-Framework 手写版） |

> 节奏怎么控：**分阶段 → 按「相关类聚合」分批（一批装同一件事的件，3~9 件合理区间、不设死上限，宁多批不量产）→ 多轮次依次实现**。每件都走满同一套六段，深度不打折；一批装多少件，判据是"每个件还能不能走满这个深度、不压成大纲句"。

## 哲学

- **快速学习为主**。——直接复刻 + 讲透，不强制手写第一版；先讲懂再复刻，学的是原理与转译。
- **参考而非照抄**。——复刻不是逐字拷贝，而是读懂"为什么这么做"后，转译成自己的代码；骨架可以照，机制也要理解后再落。
- **满深度、不分级**。——机制、DTO、建表脚本、配置都满深度讲透；差别只在份量，不在深度。档位深浅那套已废除。
- **节奏靠分批、不靠降深度**。——分阶段 + 按「相关类聚合」分批（3~9 件）多轮次推进；不是靠降深度省时间，而是靠分批让每批做得深。
- **做中学 + 具象化**。——直接复刻 + 写码先行 = 动手做；数据流/调用链/状态机这类"关系"内容用 ASCII 图/流程图画出来。
- **初学者友好**。——默认读者只懂一门语言 + 基础语法；术语/概念/机制/API 首次出现都用大白话 + 生活化例子点一句，不许甩名词、不许用术语解释术语。
- **证据先于断言**。——每批完成即构建验证并如实汇报；未跑不得宣称完成。

## 贡献

对这个技能提改进，建议用"技能版 TDD"：先写一个没有本技能时会翻车的场景作为用例（RED），再改技能文档直到通过（GREEN），最后收口反模式（REFACTOR）。提交前照 `SKILL.md` 的六段与满深度自查（触发与深度合规）。
