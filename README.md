# Replicate-Learning（复刻式学习 · 讲解中心版）

**照着一个成熟项目，AI 负责复刻并把每个文件讲透，讲解全文落盘成可反复阅读的教材——让你在 vibecoding 时代快速吃透它的业务、架构与代码。**

> 时代前提：**vibecoding**——代码由 AI 产出，人负责看懂、判断、指挥。所以这套方法**不要求你手写 / 复述 / 交作业**，一切"练才学得会"的东西都**以读代练**写进讲解。
> 目的：**快速学习**——直接复刻（配置/目录等惯例从原项目抄，机制/算法也从原项目复刻）并把原理讲透，产出物是**落盘的教学讲解教材**。非强制规范，适配而非照抄。

---

## 它是什么 / 解决什么问题

一个人想学会一个成熟开源项目（看懂源码、能讲清每个机制、能判断 AI 写得好不好），最容易踩的坑：看完就忘、只记住 API 调用姿势（换框架就归零）、每个类都写一长篇却抓不住重点、学到一半断了下次不知道从哪继续、讲过的内容被聊天窗口压缩折叠再也翻不到。

这个技能给出一套可操作流程：**先出《系统全景地图》看见整体** → **把项目拆成阶段** → **每批按「相关类聚合」分批，AI 先写码（自带逐行中文注释）再逐件讲透** → **每个文件都满深度（不分级、不降档）** → **底层穿透到源码与故障实证（防 API 调用工程师）** → **每批立即构建验证** → **讲解全文落盘 + 概念词典 + 逐阶段归档**（下次无缝续传，不靠对话记忆）。

它只负责「学习复刻」这一件事，不碰"从想法做一个新产品"那类场景。

## 怎么用（How it works）

**1. 先确认在哪个目录复刻。（重要）**
先问在哪做这次复刻。规范：**官方项目与复刻目录放同一级**。
- 本地已有源码：在**该项目父目录**下建复刻目录。例 `D:\dev\myapp` → `D:\dev\myapp-replica`。
- 给的是 GitHub/远程地址：先定一个"项目根"，官方 clone 进去，复刻目录也在**同级**。例 `D:\projects\myapp-book`（官方，只读）+ `D:\projects\myapp-replica`（你的复刻）。
- 好处：`diff` 对照方便、官方只读互不干扰、路径短好找。

**2. 在复刻目录建"开局四件套"（从整体到部分的第一步）。**
- `AGENTS.md`：项目名 + 当前进度 + 学习资料指针（模板见 `references/`）。
- `NOTES/00-系统全景地图.md`（**新增，强制**）：**整体认知第一课**——运行时部署图 / 一条请求真跑打穿全栈的 Trace / 数据模型全景（ER + 表↔模块读写矩阵）/ 模块依赖方向图 / **业务约束 → 架构决策推导链**。之后每个类的讲解都挂回这张图。
- `NOTES/概念词典.md`（**新增，强制**）：全局白话词典——概念讲过一次不再展开，后面只引用「见概念词典 §X」，省篇幅、可复习。
- `NOTES/阶段对照-完整性地图.md`：官方项目交付面拆成阶段勾选清单，★ = 重点/难点提示（不再是深度开关——所有文件同样满深度）。
- `docs/阶段0-开工清单.md`：跑通官方项目的命令序列 + 抓那条"打穿全栈"的请求链路。

**3. 分阶段，每批 = AI 复刻 + 完整讲解 + 落盘。**
读教材对应章 → 跑通参照 → 读答案卷对应件 → **AI 直接复刻（样板抄 / 机制复刻，源码自带逐行中文三问注释）** → 逐件照码**六段讲解**（含工程视角：直觉对照 / 故障情景 / 测试视角 / 演进视角）→ `diff` 对照 → **每批立即构建验证** → **讲解全文落盘 `NOTES/教学讲解/`** + 回填概念词典/全景图 + 归档 + commit。件多了按「相关类聚合」分批，多轮次推进。

**4. 每一件都满深度，不做分级。**
不管这个文件是复杂机制还是一个 3 行的 DTO、一段建表 SQL 或一个配置，都完整走一遍、讲到读者能看懂每一行为止。区别只在**份量**（机制行多、零件/脚本行少），**不降深度、不缩结构**。零件类用紧凑讲解模板（`references/零件类讲解模板.md`），深度不减、篇幅更省。节奏靠**分阶段 + 按主题分批**控制，不靠降深度省时间。

**5. 每件按"六段 + 工程视角"讲透。**
业务场景（具名人物+数值）→ 架构位置（挂回全景图）→ 开发四问（思路 / 设计决策 / 手法 / 数据流与边界）→ 代码逐行（整方法 + 三问注释）→ 调用链（≥8 跳带真实类名）→ 用法（可照跑 + 触发回放 + No-Framework 手写示范·阅读即可）；工程视角按值得配给（直觉对照 / 故障情景 / 测试视角 / 演进视角）。

**6. 底层穿透 L0~L4（防 API 调用工程师）。**
凡框架/工具/SDK 调用一律往下剥：**L0 源码实证**（贴真实源码片段+文件+行号）→ **L1 机制层**（它内部怎么做到的）→ **L2 手写示范**（20~40 行等价实现，够真，阅读即可）→ **L3 取舍层**（不用会出什么**具体**故障，人-时-错推演）→ **L4 故障实证**（AI 真破坏真跑，贴真实报错当讲解素材）。

**7. 核对问答（纯阅读）。**
每批文末给核对问答 + 标准答案（业务/架构/代码三层）。**答案已给、无需提交、不卡进度**——读者看完自己对，答不上回去重读或问 AI。

**8. 续传。**
每批归档到 `AGENTS.md` + 完整性地图 + `NOTES/阶段N`，讲解全文落盘到 `NOTES/教学讲解/`。下次说「继续复刻 / 接着做」，读 AGENTS.md + 系统全景地图 + 概念词典 + 完整性地图接着来，**不靠对话记忆**。

## 一个例子

你想学会一个开源知识库（RAG）项目：

1. 你说："我想学会这个知识库项目。" 它先问你在哪复刻。你给本地路径 `D:\dev\kb-src`；它建议复刻目录 `D:\dev\kb-replica`（同级），并建开局四件套。
2. 阶段0：跑通官方项目，看到"提问→检索→带引用回答"的效果；真跑一条请求，把"打穿全栈"的 Trace 抓下来写进系统全景地图。
3. 阶段1：拆地图，标 ★（如 RRF 排名融合、重排、幂等导入）。出《类清单表》。
4. 逐批：AI 按「相关类聚合」分批写码（含逐行中文注释）→ 逐个文件照码讲六段 + 工程视角（每个都满深度）→ diff → 每批立即构建验证 → 讲解全文落盘 `NOTES/教学讲解/` → 回填概念词典与全景图。
5. 每批归档 + `commit`。
6. 下次开新会话说"继续复刻"，它读 AGENTS.md + 全景图 + 词典 + 地图接着做，不丢进度。

## 安装

这是一个标准 Agent Skill：一个目录 + 一个 `SKILL.md`（frontmatter 仅 `name` + `description`，符合 [Agent Skills 规范](https://agentskills.io/specification)）。

```bash
# 把 skills/replicate-learning/ 整个目录放进你的技能目录即可：
#   ~/.agents/skills/replicate-learning        (Claude Code / Codex / Gemini CLI 均识别 ~/.agents/skills/)
#   ~/.claude/skills/replicate-learning
```

装好后，对一个学习/复刻项目说「我想学会并复刻这个项目 / 读 AGENTS.md 继续阶段 N / 讲批次 M」即可触发。

## 讲解深度（概述）

| 判定 | 深度 |
|---|---|
| **不分级——机制 / DTO / 建表脚本 / 配置一律满深度** | 六段全量（具名人物+数值、≥8跳调用链带真实类名、整方法逐行三问注释、开发四问含设计决策与备选对比、用法+触发回放+No-Framework 手写示范）+ 工程视角按值得配给（直觉对照/故障情景/测试视角/演进视角）+ 穿透 L0~L4 |

> 节奏怎么控：**分阶段 → 按「相关类聚合」分批（一批装同一件事的件，3~9 件合理区间、不设死上限，宁多批不量产）→ 多轮次依次推进**。每件都满深度；一批装多少件，判据是"每个件还能不能走满这个深度、不压成大纲句"。

## 哲学

- **vibecoding 时代的读者 = 指挥者**。——不要求手写/复述/交作业；练的是看懂、判断、指挥。一切"练才学得会"的内容以读代练写进讲解。
- **讲解全文落盘 = 教材**。——聊天会被压缩折叠，`NOTES/教学讲解/` 磁盘上的完整讲解才是能长期回看的教材。
- **整体先于部分**。——先系统全景地图（部署/Trace/数据/模块/选型推导），再阶段/批次/单件；每个类都挂回全景。
- **快速学习为主**。——直接复刻 + 讲透；配置/DTO/样板直接抄省时间，机制复刻并讲透原理（那才是学到的东西）。
- **满深度、不分级**。——机制、DTO、建表脚本、配置都满深度讲透；差别只在份量，不在深度。零件类用紧凑模板，深度不减篇幅更省。
- **参考而非照抄**。——复刻不是逐字拷贝，而是读懂"为什么这么做"后转译；答案卷不是圣旨，讲解含直觉对照与批判视角。
- **底层穿透到实证**。——防 API 调用工程师：L0 源码证据 → L1 机制 → L2 手写示范 → L3 具体故障推演 → L4 真跑实证。
- **具象化**。——数据流/调用链/状态机这类"关系"内容用 ASCII 图/流程图画出来；场景必有具名人物 + 具体数值。
- **初学者友好 + 术语到底**。——默认读者只懂一门语言 + 基础语法；概念用大白话 + 生活化类比，禁止用术语解释术语（悬空词继续拆）。
- **证据先于断言**。——每批完成即构建验证并如实汇报；未跑不得宣称完成。

## 贡献

对这个技能提改进，建议用"技能版 TDD"：先写一个没有本技能时会翻车的场景作为用例（RED），再改技能文档直到通过（GREEN），最后收口反模式（REFACTOR）。提交前照 `SKILL.md` 自查（触发与深度合规、读者模型一致、无强制读者动手环节）。
