# replicate-learning V2 Implementation Plan

> **For agentic workers:** Execute this plan task-by-task. Each task must leave a testable artifact.

**Goal:** Build an executable V2 `replicate-learning` skill that preserves the reference skill's source-fidelity workflow and adds three-book learning, experiments, architecture challenges, and independent engineering logs.

**Architecture:** Start from the reference skill as a compatibility baseline. Keep its existing templates, quality contract, source-injection tools, and lecture gates. Add a short V2 execution contract, phase references, training templates, and a lightweight self-check for the new artifacts.

**Tech Stack:** Markdown, JSON, Python 3 standard library, PowerShell for workspace verification.

**Spec:** `总方案.md`

## Global Constraints

- Keep the skill name `replicate-learning`.
- Do not require the learner to hand-write core production code.
- Store the engineering log independently from the studied project.
- Use reference repository cases for the first trial run.
- Preserve source fidelity, evidence grading, full-file coverage, disk state, and existing gates.
- Do not claim runtime validation without command output.
