# 复刻式学习方法（技能入口）

> 这是什么：**通过逐步复刻一个成熟项目来学会它**。骨架/配置从原项目抄（工程惯例），机制/算法自己手写（那才是学到的东西）。
> 非强制规范，适配而非照抄。参考，不是枷锁。
> 深入：方法论全量在 `docs/复刻式学习方法-通用.md`；讲解深度基准在 `examples/黄金样例.md`；可复用模板在 `references/`。

## 核心思路（一句话）

**抄样板（工程惯例/配置/DTO/目录结构）、写机制（算法/路由/编排/幂等/摘要等真正要掌握的）**；每类按**六段**讲透（业务场景→架构概念先补→实现四问→代码逐行→调用链→用法），按档位定讲解深度；每批 ≤3 类、宁多轮不量产；讲完给验收问题（一问一答带答案）；每批即构建验证；完成归档 `NOTES/阶段N` + 勾完整性地图 + 更新进度表 + commit。

## 第一步 · 先问在哪复刻（务必先确认目录）

开始前先问使用者：**要在哪个目录做这次复刻**。据此给目录规范——**官方项目（被复刻的原项目）和复刻目录放在同一级**最好（便于对照 diff、官方只读互不干扰、路径短好找）：

- **本地已有项目**：在**该项目的父目录**下建复刻目录。例：原项目 `D:\dev\myapp` → 复刻目录 `D:\dev\myapp-replica`（同级）。
- **给出 GitHub/远程仓库地址**：先建议一个"项目根"，把官方项目 clone 到该目录，复刻目录也放**同级**。例：`D:\projects\` 下 clone 官方 → `D:\projects\myapp-book`，复刻目录 `D:\projects\myapp-replica`。
- **确认后**：复刻目录 = 本项目根（`AGENTS.md` 就放这里面）；官方项目作为**只读答案卷**始终放在旁边，供对照与 diff。

## 第二步 · 在复刻目录建"开局三件套"

1. `AGENTS.md`：复制模板，填项目名/进度/学习资料指针（模板在 `references/AGENTS.md-复刻增量模板.md`）。
2. `NOTES/阶段对照-完整性地图.md`：把官方项目交付面拆成阶段勾选清单，**★ 标注「必亲手写机制」**（先自写第一版、AI 只做 review 与补测那批）。
3. `docs/阶段0-开工清单.md`：跑通参照环境的命令序列（阶段0 = **跑通参照**，不是写代码）。

大型项目/多阶段长周期，再额外产出一部《全链路拆解文档》当地图。

## 然后 · 每个阶段的标准循环

每阶段：读教材对应章 → 跑通参照 → 读答案卷对应类 → **抄样板/写机制** → 对照 diff → **每批立即构建验证** → 归档 `NOTES/阶段N` + 教学讲解纪要 + 勾地图 + 更新进度表 + commit。每阶段/批都**记录并归档**到磁盘，这就是后面能续传的依据。

## 续传 · "继续复刻"怎么接着做

每个阶段都已归档（`AGENTS.md` 的「当前进度+下一步」+ 完整性地图 + `NOTES/阶段N`）。所以下次用户说「继续复刻 / 接着做 / 再来」，或开了新会话，**先读 AGENTS.md + 完整性地图 + NOTES**，从当前状态续接——不靠对话记忆，磁盘就是记忆。

## 讲解分级规则（防止"每类都一样长、成本失控"）

每阶段开工先出**《讲解分级表》**：列出本阶段每个类 + 档位 + 一句分档理由，学员确认后才开讲——**档位事先定死，不随讲解中途变**。

| 档位 | 判定（自上而下命中即定） | 讲解深度 | 教学讲解记录 |
|---|---|---|---|
| **★机制**（满深度） | ①完整性地图标了 ★；或 ②含算法/状态机/协调器/路由/竞态/多步编排等**并发、分支、兜底、fail-fast 红线**逻辑；或 ③面试高频、讲"为什么需要+怎么权衡" | 六段全量（场景带具体人/数值、调用链≥8跳带类名、整方法逐行+每手法反例、用法带触发回放） | **机制深卡**（~1-2KB） |
| **中等**（半深） | 非★，但含 >1 根 if-else 的分支/状态流转/字段间校验逻辑 | 场景+调用链+关键代码段+用法，反例挑重点 | 薄摘要（一两行） |
| **样板**（精简） | 纯声明/映射/配置/DTO/常量/枚举/注解/单一用途 TypeHandler | 六段**保留但精简**（一行业务+一行架构+一行契约语义+一行用法） | 薄摘要（一行业务+一行架构+一行用法） |

- **★ 以完整性地图预先标注为准**（拆地图时已定，不靠讲解临时拍脑袋）；中等/样板按"有没有真实算法/分支/竞态逻辑"二分，客观可复现。
- 全量六段叙事**不进教学讲解**，留会话记录 + `examples/黄金样例.md` 作基准锚点。
- 开工表模板见 `references/讲解分级表模板.md`。

## 常见翻车

- 一次批量 7 个类 → 必然压成大纲句。≤3 类/批。
- 讲解与代码不同批、或"全部写完再统一讲" → 讲解先行、讲一个写一个。
- 样板也上满深度 → 烧讲解成本；分级表事先定死，不中途变档。
- ★机制让 AI 直接给完整实现 → 违反"自写第一版"；只给骨架等学员手写（学员明确授权代写除外）。
- 写码前不先走读 / 不讲调用链+数据流 → 只讲手法名 = 没讲完。
- 交付码里混入来源字眼（复刻/参照/来源于）→ 禁止；学习讲解允许溯源（两类文本分开）。
- 不分批构建验证、"全部写完再验证" → 每批即验证，证据先于断言。
