# V2 试运行手册

## 目标

首个试运行使用参考仓库已有案例，不另建业务项目。选择一个已有完整教材或核心机制的案例，验证 V2 是否能在不破坏旧闸门的前提下补齐实验、架构挑战和工程任务日志。

## 执行步骤

1. 将参考案例项目路径作为被学习项目，另指定一个独立日志目录。
2. 运行 `replicate-learning`，确认生成或读取四份基础地图。
3. 从一个核心业务闭环开始，生成第一册批次。
4. 为该闭环写一张 Prediction Card、一张 Evidence Card 和一张 Experiment Card。
5. 为同一机制写一张 Architecture Challenge，至少包含一个替代设计。
6. 生成一个真实风格 Issue，按八步协议执行到 Accept。
7. 运行旧版 `skill_selfcheck.py` 与新版 `v2_selfcheck.py`。
8. 检查三本书索引、覆盖矩阵、能力账本和独立工程日志是否互相回链。

## 当前实现范围

这一版提供可执行协议、模板、契约和 Skill 入口；自动评分、全自动故障注入、多 Agent 协作和跨项目能力比较暂不实现。它们必须在试运行暴露真实需求后再加入。

## 验证命令

在 `skills/replicate-learning` 目录执行：

```powershell
python scripts/skill_selfcheck.py
python scripts/v2_selfcheck.py
```
