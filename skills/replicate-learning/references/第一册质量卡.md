# 第一册质量卡

这是写作前速查。判据以`spec/00-质量契约.json`和当前`gate_lecture.py`为准；旧批遵守其声明版本。卡片不代替机器检查与语义审读。

| 要问的事 | 写作检查 |
|---|---|
| 本批真在讲什么 | 真实角色、输入、输出、端到端路径与文件归属 |
| 每个文件真的读了吗 | 全文件的构造、关键方法、调用、异常和副作用；有源码路径与真实行号 |
| 代码来自哪里 | 由注入工具取源码；合成片段单独标注，不带源码行号 |
| 初学者看得懂吗 | 新术语白话解释；代码前有问题；要点表讲因果；核心机制有正常与失败回放 |
| 怎样使用/扩展 | 【怎么用】与【上下游】说明真实调用；有扩展点才讲【怎么接】；⑦.5列接入步骤 |
| 证据与限制 | 源码、历史、实测、外部事实、推断分级；编译、单测、集成与未实测分开 |
| 怎样指导AI | ⑫展示真实需求、既有资产、方案、可用提示词、审查和反馈；不编造失败 |
| 可以续传吗 | 本批文件覆盖、未完成项、验证结果、下一步入口落盘 |

终检依次运行`batch_manifest.py check`、`safe_edit.py --check`和`gate_lecture.py --src`。书写中文教学注释时Java可用`//`，Python用`#`；其他语言按注入器支持规则，未知语法不强插注释。检查器不支持的部分写`NOT_CHECKED`，补人工证据或适配器。
