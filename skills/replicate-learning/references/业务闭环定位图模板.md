# 《业务闭环定位图》模板（讲解前置，落类到闭环）

> 用途：讲任何一类之前，先把「本批代码在主链路的哪一段、服务哪个业务场景」讲清楚，禁止孤立地逐类念注释。
> 出处：`../docs/复刻式学习方法-通用.md`（工作单元执行流程 · 步骤 0）。

## 主链路（把本项目的完整闭环画出来）

```
用户进来 → ① → ② → ③ → ④ → ⑤ → 用户拿到价值出去
```

（每一跳写一句人话，如：上传文档 → 解析分块 → 向量入库 → 提问 → 检索 → 生成 → 带引用回答）

## 本批代码定位

- 要讲的类 / 文件清单：
- 它们落在上述主链路的哪一段（第几跳、哪个环节）：
- 服务哪个具体业务场景（谁、何时、在哪一步用到）：

## 讲解落法

从全局定位开始，再落到具体类；每讲一类都回答「它服务闭环哪一环」，再讲"为什么放这里 / 上下游是谁"。
