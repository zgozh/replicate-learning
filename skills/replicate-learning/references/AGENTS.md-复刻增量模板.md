# AGENTS.md · 复刻增量模板（拼在基础 AGENTS.md 之后）

> 基础 AGENTS.md 一页模板（定位/目录结构/常用命令/硬性约定/Editing instructions，≤60 行）**见 `AGENTS.md-模板.md`**；通用工程约定（验证纪律/commit 规范/续接规范/协作要点）**见 `通用工程约定.md`**。下面只给**复刻场景增量**，拼接到基础模板之后。加上开局三件套的完整性地图与阶段0清单，即构成开局三件套。
> 出处：`../docs/复刻式学习方法-通用.md`（新项目快速开始模板），此处抽为可复制模板。

### 增量A · 运行资源与答案卷错开（强约束）

数据库名 / bucket 名 / 端口号全部用自己的一套（如 `<project>` / `<project>-sources` / `<project>-assets` / 错开端口号），compose 与 application.yaml 每一处同步——同机对照运行互不干扰、不与答案卷撞名。

### 增量B · 学习资料指针（喂 AI 的上下文，强制）

| 资料 | 路径 | 用法 |
|---|---|---|
| 答案卷（只读） | `<答案卷根目录>` | 对照源码 / 写完 diff |
| 系统全景地图 | `NOTES/00-系统全景地图.md` | 整体到部分第一课；每件讲解②挂回定位，边学边回填 |
| 概念词典 | `NOTES/概念词典.md` | 先修只讲本批新词，已收录词引用「见概念词典 §X」 |
| 教材地图 | `<XX-全链路开发详解.md>` | 每阶段开工先读对应章节再写码（大型项目可选） |
| 完整性地图 | `NOTES/阶段对照-完整性地图.md` | 勾选唯一依据，★=重点/难点（逻辑较难多花时间讲透，非深度开关） |

> 给 AI 的标准指令模板：「读 AGENTS.md + 系统全景地图，继续阶段 N / 讲批次 M」。

### 增量C · 学习进度表 + 会话规划

- 进度表：阶段 0～N 各自状态（⬜ 未开始 / 🔶 进行中+已完成+commit hash / ✅ 验收通过）。可放 AGENTS.md（豁免一页限制）或 NOTES，二选一定死。
- 新会话触发 = 切换大业务域 / 当前会话 token 过高 / 一个工作单元完成，三者任一。
- 续传靠持久化状态（AGENTS.md + git log + 完整性地图 + 答案卷），不靠会话记忆；磁盘当记忆（续接规范见 `通用工程约定.md` §3）。
- 会话归档：全局总览 `NOTES/NOTES.md`，阶段详情 `NOTES/阶段N-主题.md`，面试题统一进 `NOTES/面试题.md`；`NOTES/` 不进 git。
