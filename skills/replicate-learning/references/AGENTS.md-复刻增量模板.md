# AGENTS.md · 复刻增量模板（拼在基础 AGENTS.md 之后）

> 基础 AGENTS.md 一页模板（定位/目录结构/常用命令/硬性约定/Editing instructions，≤60 行）照通用 AGENTS.md 模板；下面只给**复刻场景增量**，拼接到基础模板之后。加上开局三件套的完整性地图与阶段0清单，即构成开局三件套。
> 出处：`docs/复刻式学习方法-通用.md`「新项目快速开始模板」，此处抽为可复制模板。

### 增量A · 诚实边界（强制，复刻特有）

注释/文档只写「做什么/为什么这么设计」；禁止任何来源字眼：`复刻`、`克隆`、`参照`、`照抄`、`来源于`、`学习用`、`教程`、`模仿`、`改编自`、`参考官方`、`复制自`、`clone from`、`copy from`。AI 生成代码若带此类字眼，生成后必须清理成正常说明。对外表述：「个人结合 AI 辅助 + 自研增量」。

### 增量B · 运行资源与答案卷错开（强约束）

数据库名 / bucket 名 / 端口号全部用自己的一套（如 `<project>` / `<project>-sources` / `<project>-assets` / 错开端口号），compose 与 application.yaml 每一处同步——同机对照运行互不干扰、不与答案卷撞名。

### 增量C · 学习资料指针（喂 AI 的上下文，强制）

| 资料 | 路径 | 用法 |
|---|---|---|
| 答案卷（只读） | `<答案卷根目录>` | 对照源码 / 写完 diff |
| 教材地图 | `<XX-全链路开发详解.md>` | 每阶段开工先读对应章节再写码 |
| 完整性地图 | `NOTES\阶段对照-完整性地图.md` | 勾选唯一依据，★=必亲手写 |

> 给 AI 的标准指令模板：「读 AGENTS.md 和教材第 N 章，继续阶段 N」。

### 增量D · 学习进度表 + 会话规划

- 进度表：阶段 0～N 各自状态（⬜ 未开始 / 🔶 进行中+已完成+commit hash / ✅ 验收通过）。可放 AGENTS.md（豁免一页限制）或 NOTES，二选一定死。
- 新会话触发 = 切换大业务域 / 当前会话 token 过高 / 一个工作单元完成，三者任一。
- 续传靠持久化状态（AGENTS.md + git log + 完整性地图 + 答案卷），不靠会话记忆；磁盘当记忆（对齐通用续接规范）。
- 会话归档：全局总览 `NOTES\NOTES.md`，阶段详情 `NOTES\阶段N-主题.md`，面试题统一进 `NOTES\面试题.md`；`NOTES/` 不进 git。
