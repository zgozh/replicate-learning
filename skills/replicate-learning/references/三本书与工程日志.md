# 三本书与工程日志

## 第一册：项目源码与工程实现

说明项目是什么、服务谁、业务闭环怎样走、模块如何协作、每个范围内文件做什么，以及关键源码从入口到出口如何执行。主目录：`NOTES/教学讲解/第一册-项目源码与工程实现/`。

## 第二册：实验与机制验证

每个核心机制使用 `Prediction -> Evidence -> Experiment -> Correction`。实验不可运行时记录静态证据、阻塞命令和未验证边界。主目录：`NOTES/教学讲解/第二册-实验与机制验证/`。

## 第三册：架构挑战与独立重构

用户不照抄原项目，提出等价实现、替换存储/协议/框架、删除模块后的退化分析或新领域迁移，再和原项目比较取舍。主目录：`NOTES/教学讲解/第三册-架构挑战与独立重构/`。

## 独立工程日志

工程日志不写入被学习项目的知识教材目录。默认位置是项目同级 `.replicate-learning-log/<项目名>/`，也可由用户指定。实际工程任务记录所需的 Issue、Context、Review、Test/Debug、Delivery，并链接相关教材证据；常规第一册讲解批次只维护教材、覆盖、索引和续传状态。

## 节奏：默认只第一册

第一册独立推进。第二册与第三册分别需要用户显式请求，用户明确说“三册一起”才同步推进。没有请求的册状态为 `not_requested`，不创建目录、索引、欠账或补齐期限，也不在普通“继续”时询问恢复。已有明确三册授权且未撤销的项目按已确认范围续传；旧版“第一册优先”迁移为普通默认模式，旧暂停记录只留在历史。
