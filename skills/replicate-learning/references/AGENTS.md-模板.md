```
<用 3-5 行说清代码放哪：如 src/ 业务、tests/ 测试、docs/ 文档、config/ 配置。>
```

## 常用命令
- 安装依赖：`<命令>`

## 硬性约定（不可违反）
- <约定1，如"横切关注点收敛到公共基类，业务层只写业务"；2-4 条为宜>
- <约定2，如"可选依赖必须降级，主链路永远可用">
