# 《类清单表》模板（每阶段开工 gate 第一步）

> 用途：开讲某一阶段前，先把本阶段**每个类**列全 + 每个类写一句「是什么 / 它干嘛的」，你确认范围后逐类**满深度**讲（不分档、不降深度）。
> 出处：`../docs/复刻式学习方法-通用.md`（讲解深度与类清单）/ `../SKILL.md`「分批」。

## 规则

- **每个类都满深度讲**：不分「机制 / 样板」高下，不管是一个复杂状态机还是一个 3 行的 DTO，六段都完整走一遍、讲到新手能看懂每一行为止。
- **差别只在份量，不在深度**：机制类行多、零件类行少，但「它为什么存在 / 数据从哪来 / 被谁用 / 为什么这样设计」每一类都要讲透。
- **★ 只是「重点/难点」提示**：标 ★ 的类逻辑较难、要多花时间讲透，**不是「讲深、别的讲浅」的开关**——所有类同样满深度。
- **初心者视角**：每个类那句「它干嘛的」用大白话写，不甩术语。

## 空白表（行数按本批实际类数，不固定）

| # | 类 / 文件 | 它是什么 / 它干嘛的（一句大白话） | 备注（★=重点/难点，可选） |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| … | （**本批有几个类就加几行**——8 个类列 8 行，别照着上表抄固定 3/5/6 行） | | |

> 确认后逐类照六段满深度讲；批大小 ≤3 类，宁多轮不量产。讲解中途不"临时降深"任何一类。
> **类数/编号动态**：本批实际几个类就列几行、逐类讲几个，**编号分母随批变**（批次2 是 6 类写 `类 X/6`，批次3 是 8 类写 `类 X/8`，不能出现「类 8/6」）。
